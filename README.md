# Café Profitability & Operations Dashboard

## Overview
This Power BI project analyses café profitability and operations under seasonal academic demand. The dashboard explores how revenue, profit, operating costs, product performance, school-day demand, staffing pressure, and projected savings can be used to support better operational decisions.

This project was created as a business intelligence case study to practise transforming raw data into actionable insights through Power BI dashboards, KPI tracking, and visual storytelling.

## Problem Statement
Cafés located near schools or campuses may experience fluctuating demand depending on academic calendars, school days, peak hours, and customer traffic patterns. However, fixed costs and staffing arrangements may not always adjust with these demand changes.

This dashboard aims to answer:

- How do revenue and profit change across school and non-school periods?
- Which costs have the biggest impact on profitability?
- Which products, locations, or sales modes perform better?
- When does operational pressure increase due to transaction volume?
- What recommendations can improve profitability and resource allocation?

## Tools Used

## Dashboard Features
- KPI cards for revenue, profit, total cost, fixed cost, variable cost, and transaction volume
- School-day vs non-school-day performance analysis
- Product-level sales and profitability analysis
- Location and sales mode comparison
- Peak-hour transaction analysis for staffing decisions
- Recommendation pages showing projected operational impact and savings

## Key Insights
- Profitability is affected by seasonal academic demand patterns.
- Demand is typically weaker during non-school periods while some operating costs remain fixed.
- Peak-hour transaction patterns can create operational pressure and affect manpower planning.
- Product and location performance can be used to guide promotional strategies and resource allocation.

## Recommendations
- Reduce staffing intensity during lower-demand non-school periods.
- Reallocate manpower towards peak lunch-hour demand.
- Use targeted promotions to increase in-store demand and improve product performance.
- Track revenue, costs, and staffing pressure together instead of analysing sales alone.
